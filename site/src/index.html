சீர் Seer, Tamil for order and neatness

Look at, prune and tidy your media files.

Open a folder and Seer shows what each file is made of: resolution, codec, audio layout, language and bit rate. Then remove the tracks you don't need without re-encoding, and fix the names they came with.

Build it for your Mac Source on GitHub

Free and open source, MIT licence. macOS 13 or later.

Reads files with
FFmpeg, linked into the app. Nothing shells out to ffprobe.
Removes tracks
By rewriting the file without re-encoding, so it's quick.
Deletes
To the Trash. A replaced original goes there too.
Sends
Nothing, unless you ask an AI model to suggest a name.

Inspector

One file, three tabs.

The list gives every file its resolution, codec, channels and running time, read in the background while you browse. Select one and the inspector goes further.

Swipe for Streams and Bit Rate.

What it's made of Info

Each video, audio and subtitle stream with its codec, channels, language and title, then the container, the size to the byte, and the tags. For a song that's title, artist, album and track.

What you can drop Streams

Tick a stream and press Remove. Seer can tick for you, keeping the original language or the best track in each, and says why. You still press the button.

Where the bits go Bit Rate ⌘B

Seer reads the whole file and plots its bit rate with the average and the peak, then gives each stream its share. Results are cached until the file changes.

Stream names ⇧⌘K

Fix the names a download came with.

Files often arrive with a web address where a track title should be, or "English" on the Tamil track. Clean Up Stream Names checks every video under a folder, however deep, and proposes a plain replacement such as "5.1 AC-3 448 kbps". Untick what you'd rather keep and fix the rest in one pass.

Folders

A folder gets a summary too.

With nothing selected, the inspector describes the folder: its size, its total running time, a bar with one segment per file, and a count of each codec. It's a quick way to find the one 4K file eating a folder, or the lone AAC track in an album of FLAC.

Files

Copy, move, and Android phones.

Nothing is overwritten

Copy and paste between folders, or drag rows onto a folder or a sidebar place. If a name is taken, the new item arrives as "name 2". A running transfer sits in the status bar; click it for each file's progress and a Stop button.

Your phone, in the sidebar

An Android phone plugged in by USB in File Transfer mode shows up under Locations. Browse it and copy in both directions. Seer speaks MTP itself, so there's no Android File Transfer to install.

Also

The smaller things.

File names
For a video, Seer works out Title (Year).mkv or Show S01E02.mkv from a messy release name, offline. You can also ask Anthropic, OpenAI or OpenRouter with your own API key. The key stays in the Keychain, and only the name and a few facts about the file are sent, never the media.
Keyboard
Finder's keys and selection rules: arrows, Shift to extend, ⌘↓ to open, ⌘↑ to go up, Return to rename. Every command is also in the menu bar.
Appearance
Seer follows the system's light or dark appearance and your accent colour. Teal always means video and amber always means audio, whatever the accent.
Memory
Window size, pane widths and sort order come back on the next launch. Analysis lives in a small SQLite cache, keyed by a fingerprint of each file, so a changed file is read again.
Live folders
When something else adds, renames or removes a file, the list updates on its own.

Platforms

Mac today. Windows and GNOME are drawn, not shipped.

Seer is written in Rust with GPUI, and the plan is one design on every desktop, with each system supplying its own window buttons, menus, wording and shortcuts. These are previews drawn by the Mac build: the layout is the other system's, but the font and window frame are still the Mac's. There is no Windows or Linux build yet.

Install

Build it yourself, for now.

You need macOS 13 or later. The first build takes a few minutes; later ones are quicker.

There is no download of this version yet. The files on the Releases page are the earlier Seer, from before the rewrite, and don't match anything on this page. Until a signed build is out, build it yourself.

  1. Install Rust

    Skip this if cargo already runs. Details are at rustup.rs.

    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

  2. Install FFmpeg and pkg-config

    Seer links the FFmpeg libraries, so they have to be on your Mac to build and run it. This uses Homebrew.

    brew install ffmpeg pkgconf

  3. Build Seer

    The app lands in target/release/Seer.app.

    git clone https://github.com/imran-vz/seer.git && cd seer && make app

  4. Move it to Applications

    cp -R target/release/Seer.app /Applications/

If something goes wrong

Seer quits as soon as it opens

FFmpeg is missing, or Homebrew upgraded it to a new major version since you built Seer. Run brew install ffmpeg, then make app again.

The build can't find FFmpeg

pkg-config can't find FFmpeg. Check that pkg-config --modversion libavformat prints a version; if not, run brew install ffmpeg pkgconf again and open a new terminal.

Bit rate analysis fails

Check that the file plays in another player, because it may be damaged. If it does, update FFmpeg with brew upgrade ffmpeg and rebuild. If it still fails, open an issue with the file's codec and container.
